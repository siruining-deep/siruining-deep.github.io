# Sirui Ning — Personal academic website

Static HTML/CSS website for GitHub Pages, with Home, About, and Papers pages.

Intended address: https://siruining-deep.github.io/

## Publish

1. Create the public GitHub repository `siruining-deep/siruining-deep.github.io`.
2. Upload index.html, about.html, papers.html, styles.css, README.md, .nojekyll, and the seven note PDFs to the root of `main`. `index.html` must be at the repository root.
3. In Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. Wait for the Pages deployment to finish, then visit the address above.

No package installation or build command is required. `.nojekyll` disables Jekyll processing.
